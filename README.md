# Estrato · Grabadora de clases

Sitio estático para grabar clases de Geología, transcribir audio en español y exportar apuntes con diapositivas. Los datos de las clases se guardan localmente en el navegador.

## Publicación

GitHub Actions publica automáticamente el contenido de la raíz en GitHub Pages cuando se actualiza la rama `main`. Tras el primer despliegue, el sitio estará disponible en:

https://alvarorequenac.github.io/transcripcion-geologia/

El flujo de trabajo también se puede ejecutar manualmente desde **Actions → Deploy to GitHub Pages → Run workflow**.

## Uso

Abre el sitio con conexión HTTPS. Autoriza el micrófono para grabar y usa un navegador compatible para transcribir. La primera transcripción puede descargar el modelo de voz; se requiere conexión para esa descarga. Las grabaciones y clases se almacenan en el navegador del dispositivo y no se sincronizan.

1. En **Grabar**, pulsa el botón rojo. Al terminar, púlsalo de nuevo y confirma **Detener y guardar**.
2. En la clase guardada, pulsa **Transcribir en español** y espera a que finalice. El texto se guarda automáticamente en el dispositivo.
3. Pulsa **Descargar Word o PDF** —o abre la pestaña **Exportar**— y elige **Word (.docx)** o **PDF**.

En Android, usa el menú de Chrome → **Instalar app**. En iPhone, usa Safari → **Compartir → Agregar a inicio**.
